# proyecto_iot_tpi
Modelo de proyecto IoT para que los estudiantes de los 7mos tomen como ejemplo para desarrollar su proyecto para el TPI. Utiliza las siguientes tecnologías:
+ Script en Python: Para simular un sensor de temperatura y humedad ambiente (DHT11).
+ Librería MQTT: Como protocolo de comunicación.
+ NodeRED: Para desarrollar los flujos de trabajos necesarios.
+ InfluxDB: Para almacenar los registros.
+ Telegram: Para crear un Bot que alerte con notificaciones.
